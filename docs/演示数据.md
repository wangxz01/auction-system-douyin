# 演示数据 (Demo Seed)

本文档说明项目自带的演示种子数据：14 个演示账号 + 8 场拍卖 + 完整出价历史 + 评论历史 + 行为埋点 + 1 笔订单，可让你 clone 完仓库后立刻进入有内容的演示状态。

---

## 1. 启用方法

### 1.1 首次启动灌入

在 `backend/.env`（不是 `.env.example`）里加一行：

```dotenv
SEED_DEMO_DATA=true
```

然后正常启动后端：

```bash
cd backend
go run ./cmd/server
```

启动日志里会看到：

```
[seed] populating demo data...
[seed] OK: 2 merchants / 12 buyers / 8 auctions
```

之后即可在前端 `http://localhost:5173/` 看到 5 场进行中的拍卖、1 场即将开始、1 场已成交、1 场已取消，共 8 个 lot。所有 active 拍卖的结束时间都会按首次灌入时间动态设置到 14-28 天后，演示窗口大于 10 天。

### 1.2 后续启动会自动跳过

`SeedDemoData` 用是否存在任意 `demo-%` 用户做幂等检测：

```
[seed] demo data already present, skipping
```

不会重复灌入，可以放心保持 `SEED_DEMO_DATA=true`。

### 1.3 生产环境必须关闭

演示账号统一使用弱密码 `demo1234`，生产环境务必：

```dotenv
SEED_DEMO_DATA=false
```

## 4. 出价历史的分布规律

为了让排行榜 / 出价历史看起来"真"，种子代码这样安排：

- 每个 active 拍卖的 N 条出价，amount 从 `start + 1×step` 一直递增到 `start + N×step`（即当前价）
- 出价人在 12 个 demo-buyer 里轮换（不同拍卖偏移不同），所以每个买家都至少出过几次价
- 出价时间均匀分布到过去 4~7 天，最早一条 ≈ `7 天前`，最新一条 ≈ `1 小时前`
- 排行榜 Top 5 永远是最高的 5 笔，第一名 = winner

这保证：
- 进入直播间能看到滚动的出价历史和 Top 5
- 登录 `demo-buyer-N` 进 `/me/bids` 能看到自己参与过的拍卖
- 商家后台 `/admin/auctions/:id` 能看到完整出价列表

## 5. 演示中的常见操作

### 5.1 演示一次出价

1. 浏览器 A：登录 `demo-buyer-3`（密码 `demo1234`），进入大厅，点开任意 active 拍卖
2. 浏览器 B（隐身窗口）：登录 `demo-buyer-7`，进入同一拍卖
3. A 点 `+¥100` 出价 → B 立即看到价格弹跳、排行榜变化、被超越 toast
4. B 反击 → A 看到自己被超越

### 5.2 让某场拍卖立刻结束（演示成交）

推荐方式：用 `admin` 登录商家后台，进入 `/admin` 或拍卖详情页 `/admin/auctions/:id`，点击 `Finish` / `强制结束`。

- 如果当前拍卖已有领先者，后端会按当前价把状态改为 `finished` 并生成 1 笔订单。
- 如果没有领先者，状态会改为 `finished`，但不会生成订单。
- 这个操作只允许 `ADMIN_USERNAMES` 中的超级管理员执行。

备用 SQL：

```sql
-- 让「清代青花瓷瓶」立刻到期，下一轮 5s 调度会判定为 finished 并生成订单
UPDATE auctions
SET ends_at = NOW() - INTERVAL 1 SECOND
WHERE title = '清代青花瓷瓶' AND status = 'active';
```

### 5.3 让 pending 拍卖（Lot 6）立刻开始

商家后台找到「当代名家国画《山居图》」点 `Start`，或者：

```sql
UPDATE auctions
SET status = 'active', started_at = NOW(), ends_at = NOW() + INTERVAL 20 DAY
WHERE title = '当代名家国画《山居图》' AND status = 'pending';
```

### 5.4 删除单个演示拍卖

推荐方式：用 `admin` 登录商家后台，进入拍卖详情页 `/admin/auctions/:id`，点击「删除拍卖」。

后端会在一个事务里删除该拍卖关联的：

- `orders`
- `bids`
- `comments`
- `user_events`
- `auctions`

备用 SQL：

```sql
-- 替换 N 为目标 auction_id
DELETE FROM bids   WHERE auction_id = N;
DELETE FROM orders WHERE auction_id = N;
DELETE FROM comments WHERE auction_id = N;
DELETE FROM user_events WHERE auction_id = N;
DELETE FROM auctions WHERE id = N;
```

### 5.5 删除演示用户

用 `admin` 登录 `/admin`，在页面底部 `Demo Users` 面板可以看到所有 `demo-` 前缀演示账号。

点击某个用户的 `Delete` 后，后端会：

- 只允许删除用户名以 `demo-` 开头的用户，避免误删真实账号
- 清理该用户的出价、评论、订单、行为埋点
- 如果删除的是演示商家，会同步删除该商家拥有的演示拍卖及其关联数据
- 如果该用户曾是某场拍卖领先者，会清空对应 `winner_id`

## 6. 完整重置：清除全部演示数据

如果想把数据库恢复到"全新没种子"的状态（保留 admin 账号、清掉所有 demo-*）：

```sql
-- 1) 删 demo 用户参与的所有出价 / 行为埋点
DELETE FROM bids
 WHERE user_id IN (SELECT id FROM users WHERE username LIKE 'demo-%');
DELETE FROM user_events
 WHERE user_id IN (SELECT id FROM users WHERE username LIKE 'demo-%');

-- 2) 删 demo 商家拥有的拍卖关联资源
DELETE FROM orders
 WHERE auction_id IN (
   SELECT id FROM auctions WHERE seller_user_id IN (
     SELECT id FROM users WHERE username IN ('demo-merchant-1','demo-merchant-2')
   )
 );
DELETE FROM comments
 WHERE auction_id IN (
   SELECT id FROM auctions WHERE seller_user_id IN (
     SELECT id FROM users WHERE username IN ('demo-merchant-1','demo-merchant-2')
   )
 );
DELETE FROM bids
 WHERE auction_id IN (
   SELECT id FROM auctions WHERE seller_user_id IN (
     SELECT id FROM users WHERE username IN ('demo-merchant-1','demo-merchant-2')
   )
 );
DELETE FROM user_events
 WHERE auction_id IN (
   SELECT id FROM auctions WHERE seller_user_id IN (
     SELECT id FROM users WHERE username IN ('demo-merchant-1','demo-merchant-2')
   )
 );
DELETE FROM auctions
 WHERE seller_user_id IN (
   SELECT id FROM users WHERE username IN ('demo-merchant-1','demo-merchant-2')
 );

-- 3) 删 demo 商家表 + demo 用户
DELETE FROM merchants
 WHERE user_id IN (SELECT id FROM users WHERE username LIKE 'demo-%');
DELETE FROM users WHERE username LIKE 'demo-%';
```

清完后重启后端，如果 `SEED_DEMO_DATA=true` 会自动再灌一次。

## 7. 注意事项

| 事项 | 说明 |
|---|---|
| 弱密码 | `demo1234` 只能用于本地演示。任何 release 环境都必须 `SEED_DEMO_DATA=false` |
| 图片来源 | 使用 picsum.photos 占位图（按 lot seed 固定），第一次加载需要联网 |
| 真实视频 | 拍品没有真实直播流，进直播间会自动 fallback 到 `frontend/public/live.mp4` |
| 时间相关性 | ends_at 是种子运行时的"NOW + N 天"，灌完两周后查看仍至少有 1 个拍卖在 active 状态 |
| 评论和行为埋点 | 种子会给 active 拍卖预置评论和 `enter_room` 行为；演示用户进直播间 / 点出价倍数还会继续产生真实的 `user_events` 行（管理端 metrics 的 today_events 会增长） |
| 二次灌入 | 已有种子时再启动会跳过，不会重复 |
| 模型变更后失效 | 如果将来改了 models 字段，老的种子代码可能需要同步更新；当前与 stage 13 的字段对齐 |
